One sentence, at most 200 characters, about the best meal I ever had — my
grandmother's rendang in Padang: beef collapsing in coconut gravy, the
kitchen thick with lemongrass, so rich I licked the spoon clean and asked
for seconds before I'd finished the first plate.

Run it with:

```sh
node main.ts
```

It writes the sentence to `/output/entry.txt` and prints it.
